From API to awareness.

A scheduled GitHub Action queries Microsoft's public Status API, validates the response, and publishes a static snapshot to GitHub Pages.

  1. 01 / CollectOne anonymous API request per run.
  2. 02 / PublishA JSON snapshot and this static page.
  3. 03 / ObserveSpot reported impact or a failed check.
A status example, not a monitoring guarantee. Scheduled runs can be delayed or skipped. Snapshots become stale after 40 minutes. This is not predictive, real-time, organization-specific, or Azure subscription health. Always consult the official portal for authoritative incident details.
